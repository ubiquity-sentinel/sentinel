The line and its sidings

step on the main line jam: nothing moves it, or it loops without progress owner-gated park terminal by design correction loop back to work

Corrections and CI fixes never open a new pull request. When a record already has a PR, the publish step pushes the new commit to that PR's branch and goes straight back to review. A new PR opens only on first publish, or when the old PR was closed without merging. The one place a PR gets detached is the refresh-failure jam (Sentinel PR #160), and its fix keeps the PR attached. Every arrow is a real decision function in the Sentinel source; labels name the function that takes the step. Red boxes are the jams the live classification found: either no runtime step and no launcher planner ever changes them, or they change every pass without getting closer to a merge.

A PR whose CI fails before its first review is parked. Under gen 80 the fix route is off, and re-admission only happens at the exact base it was parked on. The base moves on every merge, so nothing re-admits it.

PRs #999, #1053 and #1011. An ambiguous review request with no bound journal is deferred on every run. That branch skips the expiry check every other branch has.

Task acceptance not fulfilled

When the review says the PR doesn't do what the issue asks, the record is blocked, even with review rounds left. The fix sends it back as a correction while rounds remain, and parks it visibly once they're spent.

Retrying the same failure

Issue 300 fails the model run the same way every attempt. Attempt memory never refuses because the base keeps moving, so it charges a reservation every 1–2 passes until a silent cap of 200.

Waiting on a disabled release

B12 · 25 recordsqueued

Merged PRs with closed issues wait for a Gateway release record that never comes, because the release path is off. Each pass rewrites all 25. The work itself is done.

Red heads hold the merge line

J3 · throughputqueued

The ai.ubq.fi line is ordered by PR number. Lower-numbered PRs still waiting on a CI fix sit ahead of green, reviewed ones like 698 and 879, which adds hours to every merge.
